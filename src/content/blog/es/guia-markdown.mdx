Markdown es un lenguaje de marcado ligero que permite crear documentos con formato usando texto plano. Es la forma más natural de producir contenido en sitios basados en Astro como Zahit.

## Encabezados

```
# Encabezado H1
## Encabezado H2
### Encabezado H3
```

## Formato de texto

Usa dos asteriscos para el **texto en negrita**, uno para la *cursiva* y dos virgulillas para el ~~texto tachado~~.

> Usa `>` para las citas en bloque. Es una excelente forma de destacar frases importantes para el lector.

## Listas

Lista sin ordenar:
- Primer elemento
- Segundo elemento
  - Elemento anidado
- Tercer elemento

Lista ordenada:
1. Haz esto primero
2. Luego esto
3. Por último, esto

## Enlaces e imágenes

Puedes agregar enlaces con el formato [sitio oficial de Astro](https://astro.build).

## Bloques de código

Usa comillas invertidas para el `código` en línea.

```javascript
function zahit() {
  return 'La simplicidad es profundidad, no carencia.';
}
```

## Tablas

| Sintaxis | Descripción |
|----------|-------------|
| `**negrita**` | Texto en negrita |
| `*cursiva*` | Texto en cursiva |
| `[texto](url)` | Enlace |

Aprender Markdown lleva unos minutos; dominarlo te da libertad.
